# Decision records

This directory holds Orpheus Edge decision records. Each record captures one
significant decision, its context, what it changed, and the consequences. The
format follows the Talos repository's `docs/adr/` entries. A record is immutable
once Accepted; a later decision supersedes rather than rewrites an earlier one.
